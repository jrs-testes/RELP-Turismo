# RELP Turismo - Site Jekyll

## Como Editar
1. Altere dados em `_data/site.yml` (telefone, horários, textos).
2. Troque fotos adicionando arquivos em `/assets/images/` e referenciando no site.yml.
3. Para publicar: push para branch `main` no GitHub. Ative GitHub Pages em Settings > Pages > Source: main.

## Dados Fictícios
Este site usa dados de exemplo para aprendizado. Substitua por informações reais antes de publicar.
